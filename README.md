# Podi Bottle

A mobile-first perfume storefront built with plain HTML, CSS, and JavaScript. It has no package dependencies, build step, database, or checkout service. The enquiry form opens WhatsApp with the selected scent and size filled in.

## Deploy to Vercel

1. Import this folder's Git repository into Vercel, or run `vercel` from this directory.
2. Select **Other** as the framework preset if Vercel asks.
3. Leave the build command blank and set the output directory to `.`.
4. Deploy.

The site is static, so there are no environment variables to configure. For a local preview, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

The fragrance list and the 8-hour roll-on guarantee follow the seller-provided brief. Availability and current prices are left for the seller to confirm directly.
